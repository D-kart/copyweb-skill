# copyweb 六阶段复刻流程图

> 每阶段：做什么 / 用什么工具 / 产出什么 / 已知坑。加载 SKILL.md 时无需读本文件；执行到某阶段拿不准时再查对应段落。

```
┌─────────────────────────────────────────────────────────────────────┐
│                          输入：参考网站 URL                            │
└─────────────────────────────────────────────────────────────────────┘
                                   │
        ┌──────────────────────────▼──────────────────────────┐
        │ 阶段0 · 命名与去重                                     │
        │ 工具：GitHub/npm/Product Hunt 搜索                    │
        │ 产出：style_name（短词）+ 中文别名 + positioning       │
        │ 坑：撞车已知产品（obsidian→Obsidian Notes）；绑品牌名   │
        └──────────────────────────┬──────────────────────────┘

        │    → 区块清单 + 每区块用途                             │

        │    → :root 变量 / @font-face / font-family /          │

        │  2. 主色(>70%) vs 反色锚点(<30%)                       │

        │  4. 卡片/布局：边框/圆角/阴影/hover/最大宽/纵向节奏      │
        │  5. 提炼 2-4 个签名级视觉元素                          │
        │ 产出：结构化分析数据（喂 design-system.md）            │
        │ 坑：把反色锚点当主调（panda "暗黑系"误判）              │
        │  → 详见 references/analysis-checklist.md              │

        └──────────────────────────┬──────────────────────────┘
```
